Excluir conta SoloForte

Pedido de exclusão da conta e dos dados associados · iPhone e Android

O caminho mais direto é dentro do aplicativo: Configurações → Excluir minha conta. Confirme em Excluir Permanentemente. O app apaga a conta no servidor, remove os dados locais dessa conta e encerra a sessão.

Pedir por esta página

Use este formulário se você não consegue entrar no app. O pedido vai para privacidade@soloforte.app. Envie o e-mail da conta. Não envie a senha.

A exclusão é permanente. Ela remove a conta de acesso e os dados associados: perfil, clientes, fazendas, talhões, visitas, ocorrências, relatórios, fotos, áudios e preferências ligadas a essa conta. Um registro só permanece se a lei exigir a guarda.

Se o botão não abrir o aplicativo de e-mail, escreva para privacidade@soloforte.app com o assunto “Exclusão de conta SoloForte”.

O que acontece depois

O pedido identifica a conta pelo e-mail informado. Quando a exclusão termina, aquele login deixa de existir. Arquivos que permanecerem só no aparelho, num pedido feito por e-mail, saem ao apagar os dados do app ou ao desinstalar.

Detalhes do tratamento de dados estão na Política de Privacidade.
