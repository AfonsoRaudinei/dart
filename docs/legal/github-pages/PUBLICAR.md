# Publicar no GitHub Pages

Substitua o site do repositório que o app já abre:

`https://afonsoraudinei.github.io/SoloForte-Pol-tica-de-Privacidade/`

Coloque estes arquivos na raiz desse repositório, com GitHub Pages na branch `main` e pasta `/`:

- `index.html`
- `exclusao-de-conta.html`
- `suporte.html`
- `style.css`

URLs para as lojas, depois que a página abrir no navegador:

| Campo | URL |
|---|---|
| Política de Privacidade (App Store e Play) | `https://afonsoraudinei.github.io/SoloForte-Pol-tica-de-Privacidade/` |
| Exclusão de conta (Play, Data safety) | `https://afonsoraudinei.github.io/SoloForte-Pol-tica-de-Privacidade/exclusao-de-conta.html` |
| Suporte (App Store, Support URL) | `https://afonsoraudinei.github.io/SoloForte-Pol-tica-de-Privacidade/suporte.html` |

O app já aponta a Política de Privacidade para a primeira URL. As outras duas passam a existir quando estes arquivos estiverem no ar.
